# IspeakLLM

Open-source toolkit that makes any website speak LLM, on any host:

- **Speak** — llms.txt (v2), llms-full.txt, per-page Markdown, `Accept: text/markdown` negotiation.
- **Declare** — one AI-use policy compiled to Content-Signal, AIPREF, `__usage_ai-training`, robots.txt, RSL, ai.txt, TDM.
- **Prove** — JCS + Ed25519 signed, content-addressed manifests, verifiable offline.
- **Know** — honest agent identity grading (claimed vs verified, RFC 9421 Web Bot Auth).
- **Answer** — read-only per-site MCP server.
- **Check** — llms.txt linter and agent-readiness checker.
